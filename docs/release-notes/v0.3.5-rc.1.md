Experimental remote I/O prerelease. DuckDB 1.5.4–1.5.6 remain the supported engine line; DuckDB 2.0.0 remains evaluation compatibility. Source commit: `55d66f3fbd3199d7471b8cd569c43cc91a8cec7e`.

- Adds bounded remote range merging, actual concurrency metrics, memory-pressure limits, and DuckDB 2.0 AsyncResult integration.
- **No consistent async speedup is demonstrated.** Experimental cross-batch prefetch defaults to disabled (`duckomo_async_prefetch_batches=1`). An explicit four-batch HTTP O1280 run measured 1351→1910ms and 840→1523 requests with identical results.
- Some first local queries exceed the 5% performance target. Spec 008 is not declared complete. See [measured results](https://github.com/chorust/duckomo/blob/v0.3.5-rc.1/evidence/008/prefetch/report.md).

Validation: four-engine ARM64 compatibility CI passed; all 16 engine/platform release binaries passed their matching official runtime local/HTTP smoke checks. Local SQL/native, ASan/UBSan and system-allocator TSan evidence is included in the source. [Release workflow](https://github.com/chorust/duckomo/actions/runs/40178444705).

Unsigned binaries match the exact DuckDB version and platform in each filename. Verify `SHA256SUMS`, unzip, and use `duckdb -unsigned` to install/load the local extension. Official HTTPFS is a separate dependency. These checks do not constitute full production-grid or independent-reproduction acceptance.
