# DuckOMO v0.3.0

DuckOMO now reads polygon regions directly from a single OM object and can bind one selected value array before scanning. SQL still performs aggregation over the returned raw grid records.

- Add experimental `read_om_regions` with standard WKB Polygon/MultiPolygon input, explicit `grid_lonlat` reference, planar `covers` membership, region IDs, and optional source positions. Load a matching DuckDB spatial extension explicitly.
- Add `variable := 'column_name'` to `read_om`, `read_om_regions`, and `om_grid_info`. Names use encoded canonical column paths; dimensions MAP declarations cover only the selected array.
- Reuse immutable bound metadata by default. `SET duckomo_revalidate_metadata=true` enables full-tree rereads and comparison of the same bound view; the source object must remain stable during a query.
- Coalesce compact root metadata directories with a bounded read, and fall back for sparse layouts. Fix nested/escaped single-column projections, empty-directory crashes, metadata-order dependence, and selected-variable strict-mode failures.
- Fix empty polygon ring handling and account for candidate positions, coordinate work, metadata buffers, and temporary schemas. Bind regression evidence to the actual version-specific and sanitizer artifacts.
- Add Qinghai administrative-polygon and Nino SST examples in both READMEs, including CRS84 boundary preparation and producer-based ERA5 chunk timestamps.

Validation on Linux ARM64 includes new builds for DuckDB v1.5.4/v1.5.5/v1.5.6 and equivalent local aggregations. The final v1.5.5 build passed 32 native checks, 19 SQL files, 12 Python suites, 16 ASan/UBSan checks, domain references, and region P0–P4. For the same Qinghai AVG query, one real public-S3 measurement improved from 208.2 seconds to 39.5 seconds with identical results; metadata bind positional reads fell from 638 to 4 while metadata bytes increased from 47 KB to 486 KB. Positional-read counts are not independently observed HTTP requests.

GitHub packages are unsigned and must match the exact DuckDB version and platform. Download the asset, verify SHA256SUMS, decompress to `duckomo.duckdb_extension`, and install locally using `duckdb -unsigned`. Official HTTPFS and spatial are separate runtime dependencies.

Polygon support remains experimental. Release local/HTTP smoke checks do not replace full scientific-grid acceptance, current-source P5–P7, or cross-platform independent reproduction. See the tagged source's `docs/releases.md` and `specs/005-polygon-region-statistics/evidence/metadata-selection-fixes.md` for validation scope.
