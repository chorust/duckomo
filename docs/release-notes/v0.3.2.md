# DuckOMO v0.3.2

Add experimental nearest sampling for polygon regions through `read_om_regions`, with sampling status, source coordinates, distance, axis indices, and source-record provenance. The supported sampling profiles are synthetic regular spherical grids and NCEP GFS025; other registered domains remain outside this acceptance scope.

- Add nearest-point lookup and region sampling execution, including projection, filtering, parallel worker lifecycle, and memory accounting.
- Extend native and SQL regression coverage, scientific reference fixtures, and three-version validation tooling for DuckDB v1.5.4–v1.5.6.
- Bind validation commands to verified build manifests and executable identities. N6 rejects stale command records and verifies N0 replay SQL, rows CSV, and metrics CSV hashes.
- Include the feature specification, contracts, implementation plan, and historical validation evidence.

The audit fixes passed 17 Python tests. Complete runtime and remote-service acceptance was not rerun after these fixes; historical evidence packages without the newly required fields must be regenerated before they can pass the updated N6 auditor. Historical passing verdicts do not certify the current tree.

Packages remain unsigned and require the exact DuckDB version/platform. Spatial and HTTPFS remain separate dependencies. This version update does not establish complete cross-platform or independent acceptance.
