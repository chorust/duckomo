# DuckOMO v0.3.1

SEAS5/EC46 objects can now bind their Gaussian domains directly. Adjacent selections also reuse each decoder's existing index and compressed-data buffers, avoiding thousands of repeated small remote reads.

- Add eight O320 domains: `ecmwf_seas5`, `ecmwf_seas5_ensemble_mean`, `ecmwf_seas5_daily`, `ecmwf_seas5_daily_ensemble_mean`, `ecmwf_seas5_monthly`, `ecmwf_ec46`, `ecmwf_ec46_ensemble_mean`, and `ecmwf_ec46_weekly`.
- Add N160 domains `ecmwf_seas5_12hourly` and `ecmwf_seas5_monthly_upper_level`, including producer N-series CRS remarks. O320 and N320 remain distinct grids; product domains share their actual spatial definitions.
- Reuse fully contained ranges in worker-local, variable-local decoder buffers. Invalidate a range before replacement and publish it only after a successful read. No extra payload buffers or cross-query cache are introduced.
- Keep logical requests and repeated decompressions observable. Physical read metrics count actual I/O; decoded block counts do not claim decompression reuse.
- Update both READMEs and add a seasonal domain guide with monthly Nino polygon examples, actual time coordinates, member-axis behavior, and raw-unit caveats.

For the complete two-region, seven-month Nino query, actual public S3 HTTP logging recorded 1 HEAD and 156 Range GETs, all successful, in 24.4 seconds (another run took 26.0 seconds). The previous implementation's same-file/query controlled HTTP replay made 15,325 requests; its complete S3 query exceeded 300 seconds. Value index/data reads fell from 7,652 each to 13/123. All 14 aggregate groups match local results. These are scoped measurements, not a universal cold-network benchmark.

Validation includes complete local SQL/native/Python regressions, independent O320 full-position coordinates, all ten seasonal domains with time/member/CRS fixtures, real O320 static and monthly/weekly sample comparisons, decoder read-failure recovery and contained-range offsets, region cancellation/isolation, and ASan/UBSan reader checks. The two N160 product domains have pinned producer definitions and synthetic validation; public real run samples were not acquired.

The tested SST object's metadata labels its unit as Celsius while its raw values are about 271–304. DuckOMO preserves raw values and does not silently convert units. See `docs/seasonal-domains.md` for the sample and scope.

Packages remain unsigned and must match the exact DuckDB version/platform. Download, verify SHA256SUMS, decompress to `duckomo.duckdb_extension`, and install with `duckdb -unsigned`. HTTPFS and spatial are separate dependencies. Polygon reads remain experimental; release smoke tests do not replace full scientific-grid or independent acceptance.
