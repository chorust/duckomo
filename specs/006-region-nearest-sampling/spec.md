# Feature Specification: 统一区域入口的最近邻采样

**Feature Branch**: `main`（未创建或切换分支；规格目录独立于分支）

**Created**: 2026-10-15

**Status**: Implemented locally on Linux AArch64; N0–N4 pass for their declared scopes, including the refreshed N1/N2 profile acceptance. N5's local and controlled-transport subchecks pass, but durable raw-input authorization/archive is unresolved; N6 remains incomplete. A local 5×5 N7 reproduction exists, but its executor participated in implementation and does not meet the independent-executor contract. Overall acceptance remains incomplete. See the [current acceptance status](evidence/final.md) and [gate evidence](evidence/) for scope and limitations.

**Input**: 用户已确认：“在现有 read_om_regions 里面通过 method 选择，不再增加采样函数”，并同意将该设计作为独立 spec。目标是解决东城区等小区域在 GFS 0.25° 粗网格中没有内部采样点、无法取得区域代表值的问题，同时保持现有原始区域选点行为。设计背景见[空间采样与区域计算提案](../../docs/plans/2026-10-14-spatial-sampling-and-computation.md)，外部来源见[生态调研](../../docs/research/2026-10-14-spatial-computation-ecosystem.md)。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在同一个区域入口取得小区域代表值 (Priority: P1)

分析者提供东城区等行政区多边形，希望在既有区域查询中显式选择最近邻方法，取得区域代表位置的气象值，无需学习或切换到新的采样函数。所选源点允许在行政区外，结果可说明目标位置与实际来源。

**Why this priority**: 当前小区域没有内部网格点时会返回零行；显式代表点采样直接满足“小行政区也可以查询天气”的需求。

**Independent Test**: 对固定粗网格及不含任何采样点的小多边形，通过同一个区域入口分别执行默认选点与最近邻采样；前者零行，后者返回可追溯到邻近源点的代表值。

**Acceptance Scenarios**:

1. **Given** 一个有效小多边形没有覆盖任何源点、其代表位置处于数据覆盖域内，**When** 显式选择最近邻方法，**Then** 每个原始非空间轴位置组合返回一个区域结果，值等于选定源点的原始值，不要求源点位于面内。
2. **Given** 本地冻结的东城区边界与 ncep_gfs025 文件，**When** 选择最近邻方法，**Then** 源位置为经度 116.50°、纬度 40.00°，结果值与直接读取同一原始记录一致，输出位置是面内代表位置。
3. **Given** 用户查询多个区域，部分区域映射到同一源点，**When** 完整执行采样，**Then** 各区域分别保留结果与身份，不因来源相同合并区域。
4. **Given** 文件有多个值变量、时间、成员或层次，**When** 查询最近邻结果，**Then** 所有兼容变量使用同一空间来源，每个非空间轴位置保持独立，缺测状态按变量分别表达。

### User Story 2 - 保持现有查询习惯并知道何时使用哪个入口 (Priority: P1)

既有用户仍能读取区域内原始点并做等权统计；新用户根据“普通网格数据”或“已有多边形区域”选择入口，再通过一个方法参数决定区域处理方式。

**Why this priority**: 增加函数或改变默认结果会提高学习成本，也可能使原始点均值和代表位置估计混淆。

**Independent Test**: 原 005 的区域查询在省略方法时保持结果、列名、类型、顺序与来源语义；显式原始点方法得到相同结果，最近邻仅通过方法参数启用。

**Acceptance Scenarios**:

1. **Given** 一个已有区域读取语句，**When** 省略方法或显式选择 points，**Then** 返回的原始记录多重集合、schema 和计数语义一致；原有无点区域仍零行，不隐式使用最近邻。
2. **Given** 一个已有区域读取语句，**When** 仅增加 method 为 nearest，**Then** 使用同一个 read_om_regions 入口和原变量列名；默认生成面内代表位置，无需同时提供另一个模式参数。
3. **Given** 用户阅读接口指南，**When** 选择查询入口，**Then** 指南明确普通文件/网格/矩形坐标筛选使用 read_om，已有行政区或流域多边形使用 read_om_regions，并分别提供原始点与最近邻示例。
4. **Given** 用户指定未知方法、尚未实现的插值方法，或在 points 模式显式传入仅适用于采样的策略，**When** 请求绑定，**Then** 明确拒绝，不静默忽略或切换算法。

### User Story 3 - 解释空值、距离与实际来源 (Priority: P1)

分析者需要区分“区域没有代表位置”“位置超出覆盖”“最近点太远”和“该时刻源值缺测”，并检查源坐标与距离，避免把空值解释成零或把区外点当成区内观测。

**Why this priority**: 最近邻能返回值并不保证它对区域足够有代表性；可解释状态与来源是结果可信的必要条件。

**Independent Test**: 在一个固定网格中设置空面、域外区域、距离阈值内外目标、源点缺测及多变量混合缺测，逐项核对结果行、NULL、状态和来源。

**Acceptance Scenarios**:

1. **Given** 最近点某个变量在一个时刻缺测，**When** 采样，**Then** 该变量返回 NULL 和 source_null，仍保留原选定源点；其它有效变量不受影响，不寻找更远的有效点。
2. **Given** 代表位置在区域网格覆盖域外，**When** 使用默认域外策略，**Then** 保留该区域—轴组合的结果，值为 NULL、状态为 outside_domain；显式严格策略使整个查询失败。
3. **Given** 指定最大距离且最近点距离超过上限，**When** 采样，**Then** 返回 NULL 和 beyond_max_distance；距离等于上限时允许采样。
4. **Given** 有效 EMPTY 多边形，**When** 选择 nearest，**Then** 每个非空间轴组合返回 empty_geometry、NULL 坐标和值，不制造原始源身份；NULL 或非法几何仍整体拒绝。
5. **Given** 选定源点有原始值且用户要求来源详情，**When** 查询，**Then** 来源指向实际原始记录，输出的代表位置与真实源坐标可分别识别。

---

### User Story 4 - 在大对象和多维查询中正确执行局部采样 (Priority: P2)

分析者对本地或远程大对象的多个区域进行采样，希望只读取计算所需的值；排序、过滤、线程数、取消及失败恢复不改变结果含义。

**Why this priority**: 返回一行不应要求先读取全部值；同时不能为了局部读取而裁掉区域外的正确最近源点。

**Independent Test**: 固定可跳块对象，比较最近邻结果与独立源记录读取；核查坐标/无值计数路径无值读取，值条件在最终结果上执行，并比较不同线程和来源的完整结果。

**Acceptance Scenarios**:

1. **Given** 只查询目标/源坐标或无值条件计数，**When** 完整执行，**Then** 不读取或解码值数据；请求缺测状态或值过滤时正确保留对应变量依赖。
2. **Given** 最近点位于区域包围框外，**When** 采样并按输出坐标或值筛选，**Then** 先确定正确来源再应用最终筛选，不因原区域包围框或源值条件丢掉该点。
3. **Given** 固定文件与区域，**When** 分别以 1、2、4 个工作线程或本地、HTTP、S3 来源执行完整查询，**Then** 区域—非空间轴结果多重集合、源身份中的位置、值和状态相同；不同 URI 的对象身份无需相同。
4. **Given** 取消、读取错误或提前停止，**When** 之后执行有效请求，**Then** 能正常完成；前一次不完整扫描不被记录为完整采样成功。

### Edge Cases

- 空区域集合：完整验证原有参数后返回零行；不隐瞒文件或声明错误。
- 有效非空 Polygon/MultiPolygon：默认生成一个面内代表位置；MultiPolygon 不自动拆分、跨分量平均或按分量面积选择多个点。
- 面内位置生成随几何依赖版本可能变化：返回实际位置及策略版本，不承诺跨版本相同几何总产生完全相同坐标。
- 目标恰在源点、两点等距、近似等距、降序坐标、不同存储顺序：选择规则确定，不由线程或读取顺序决定。
- 全球经度周期与区域边界：仅有完整周期证据的网格允许环绕；区域子集不能自动连接两端。
- 接缝、极区、重复环绕点、异常纬度或缺乏地球模型：在未支持能力上明确拒绝，不以近似方法冒充已承诺最近邻。
- 同一坐标、重复时间标签对应不同原始位置：保持原始轴位置，不按标签合并。
- 一个变量缺测、另一个有效；源值为 ±Inf：缺测按变量区分，非有限值沿用既有读取语义，不静默转零或另找源点。
- 原变量名与 sampling 等新模式输出列冲突：在 nearest 模式绑定拒绝；points 不新增此前不存在的保留名。
- 用户投影整个采样详情或仅查看几何详情：前者可能依赖全部所选变量的缺测状态，不能统一当成无值元数据。
- 结果总量可能为区域数与非空间轴大小的乘积：受检计数，不能溢出，也不能为调度预先物化全部组合。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在现有 read_om_regions 入口以 method 选择处理方式；省略或 points 保持原始区域选点，nearest 执行区域代表位置采样。本期不新增区域采样函数或同义单数别名，不要求 region_mode 等第二个主要选择参数。
- **FR-002**: points 模式 MUST 保持现行 005 的原始记录、列名/类型/顺序、边界、空结果、来源、缺测及筛选语义；不得在零样本时隐式改用 nearest。
- **FR-003**: nearest MUST 为每个有效非空区域默认生成一个 point_on_surface 面内代表位置，并验证它被区域覆盖；不把该位置解释为人口中心、气象站或区域均值。MultiPolygon 取整体的一个位置，不自动拆分；返回实际代表位置与策略版本。
- **FR-004**: nearest MUST 选择与代表位置在网格声明地球模型下地表距离最小的源采样位置，单位米；本期范围为有证据的完整规则经纬度球面网格，至少覆盖 ncep_gfs025。不得把逐轴标签匹配当作已证明的地表最近邻；不支持的网格/模型明确拒绝。
- **FR-005**: 对实现所定义距离计算结果相等的源位置，系统 MUST 选择最小原始 point_index；同一绑定输入与依赖版本下，线程和调度顺序不得改变代表位置或来源。近似等距的参考及数值规则须在计划阶段冻结，不用容差改变 points 的边界。
- **FR-006**: 系统 MUST 独立检查目标覆盖域。完整周期全球规则网格使用已声明全球域；非周期区域规则网格使用原始坐标轴端点围成的闭域，不自动扩展半格或夹取边缘。域外默认输出 outside_domain 和 NULL，可显式要求整个查询失败。完整周期与异常网格能力必须有证据，不能仅凭经度名称推断。
- **FR-007**: 用户 MUST 能按米指定有限非负 max_distance_m；省略表示没有额外距离限制，距离不超过上限才能返回源值，超过时输出 beyond_max_distance 和 NULL。阈值不替代覆盖域检查。
- **FR-008**: nearest MUST 先由几何确定源点，再读取对应值；同一区域的源点不随时间/member/level 或变量缺测变化。最近源值缺测保持 NULL/source_null，不搜索更远有效点，不填零；±Inf 沿用既有读取语义。
- **FR-009**: nearest MUST 每个区域 × 原始非空间轴索引组合输出一行，保留已声明的时间/成员/层次等语义列和轴位置；不自动平均、广播、重排、合并重复标签或从路径猜时间。无非空间轴时每区域一行。
- **FR-010**: nearest MUST 保留原变量列名和 FLOAT 类型，允许沿用省略 variable 读取全部兼容值数组；各变量共享空间来源，各自缺测和状态独立。顶层 lat/lon 表示区域代表位置，真实源坐标必须明确另列于 sampling。
- **FR-011**: nearest MUST 追加一个 sampling 详情列，至少可查询方法/算法与代表位置策略版本、网格/布局身份、距离模型、源坐标/点索引、距离、非空间轴位置、几何定位状态及按原变量名区分的值状态/贡献数。不要求普通调用配置或投影全部详情。
- **FR-012**: include_source MUST 沿用现有参数；nearest 匹配源点时输出真实原始 om_source，无匹配为 NULL，不伪造目标位置的原始索引。源值缺测不删除实际已匹配的来源；详情按既有脱敏规则处理，不新增同义开关。
- **FR-013**: 系统 MUST 区分 ok、empty_geometry、outside_domain、beyond_max_distance 和逐变量 source_null；EMPTY 的目标坐标/值为 NULL。最近点已确定但距离超限时保留候选源坐标和距离供诊断，不视为成功匹配、om_source 为 NULL；域外/EMPTY 不生成源候选。非法输入、缺少能力、权限、损坏或读取失败仍为查询错误，不降级为空值。
- **FR-014**: 系统 MUST 在返回结果前校验整个输入集合和所有声明，复用 005 的 ID/WKB/几何/数量限制及 grid_lonlat 参考、接缝/极区范围；方法相关参数绑定时固定。未知/NULL 方法、不支持的方法值、非法距离与不适用策略必须明确拒绝，不被 WHERE/LIMIT 隐藏。
- **FR-015**: nearest MUST 正确执行针对最终值和代表位置的完整用户筛选；不得将目标区域范围或最终值条件用于删掉计算必需源点。非空间轴筛选与列裁剪必须保留正确的值和状态依赖。
- **FR-016**: 仅坐标/来源位置与无值条件计数 MUST 不读取值索引/数据或解码值；请求值、值过滤或相应缺测状态时保留其依赖。COUNT 在 nearest 计区域—轴组合，在 points 计原始匹配记录，文档必须说明区别。
- **FR-017**: 系统 MUST 从几何确定有限源位置后读取所需值，不为了最近邻遍历全部值。局部收益需在冻结的可跳块对象上实际测量；不得因只返回一行就声称只读取一个标量或固定收益倍数。
- **FR-018**: 采样任务与工作内存 MUST 有明确边界，不随空间源点数或全部区域×非空间轴结果无界增长；计数受检，取消/错误/提前停止有诚实终态，后续查询可恢复。内部模块可独立复用，但不通过增加公共函数实现职责分离。
- **FR-019**: 本地、HTTP(S)、S3 与不同线程数 MUST 保持同输入完整结果一致；沿用已有对象稳定性、读取与脱敏错误规则。不新增跨查询缓存或来源身份承诺。
- **FR-020**: 文档 MUST 用查询目的说明 read_om 与 read_om_regions 的区别，给出默认 points 与显式 nearest 的对照、东城区案例、状态/来源及计数解释，并明确 nearest 是代表位置估计而非区域平均。bilinear、面积加权与其它未来计算不列为本期已支持方法。

### Key Entities *(include if feature involves data)*

- **区域输入**：既有区域 ID 与有效多边形集合；方法选择不改变其身份和合法性要求。
- **代表位置**：区域生成的一个面内位置，包含实际坐标、策略及版本；不同于源点和整个区域。
- **源匹配**：目标与最近原始采样位置的关系，包含距离、模型和网格/原始点身份；几何定位独立于值是否缺测。
- **区域采样结果**：区域 ID、一个原始非空间轴组合及各变量值/状态；与 points 模式的原始区域—记录关系区分。
- **采样详情**：用于解释方法、坐标、距离、轴位置、来源和各变量有效性的附加信息。
- **网格采样能力**：某一网格的覆盖、周期、地球模型、最近邻与数值规则是否已验证；可读取不等于可执行本期采样。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 冻结的东城区/GFS 案例中，默认方法零原始行；nearest 每个非空间轴组合恰好一行，源坐标为 (116.50°,40.00°)，值与同源直接读取精确一致，状态和来源可解释。（FR-001–004/008–013）
- **SC-002**: 所有冻结的小型独立穷举参考中，目标源索引、距离阈值结论和并列选择 100% 一致，覆盖降序轴、存储顺序、周期、边界、近等距和拒绝能力的案例；有明确版本与误差依据。（FR-004–007/014）
- **SC-003**: 现有区域选点验收样本在省略 method 与显式 points 两种情况下，原始结果多重集合、schema、原值和 NULL 的差异均为零；本期没有新增采样函数或单数别名。（FR-001/002）
- **SC-004**: EMPTY、域外、距离阈值内/等于/外、最近值缺测和多变量混合缺测的冻结矩阵，结果行数、NULL、状态、候选坐标与来源 100% 符合声明；权限/损坏等错误无一被吞成缺测。（FR-006–014）
- **SC-005**: 至少一个包含 3 个非空间轴、重复坐标标签和部分缺测的样本中，区域—原始轴位置结果与独立参考双向差异为零；1/2/4 工作线程及同内容本地/HTTP/S3 的值、状态和位置一致。（FR-008–012/015/019）
- **SC-006**: 固定大对象中，坐标/无值计数查询的值读取与解码均为零；代表点位于面内而源点位于面外时仍正确采样；值/详情状态过滤与独立完整计算后筛选的结果一致。固定可跳块局部样本的值数据读取和解码块数严格少于同变量的完整读取。（FR-015–017）
- **SC-007**: 固定相同区域、线程、块布局及非空间轴配置，源空间点数扩大至少 10 倍时，采样工作自有内存峰值不超过原来的 2 倍；取消/失败/提前停止后有效查询全部恢复成功，不完整采样无一报告完整结果计数。（FR-018/019）
- **SC-008**: 未参与实现的验证者仅凭交付指南，可选择正确入口并在同一区域调用中切换 points/nearest，复现一次小区域采样、一次缺测/域外辨别和一次实际来源核对；完整命令、输出和结论可追溯。（FR-020）

## Assumptions

### 已确认范围

- 这是独立 006 spec，扩展 005 的区域处理，不改写 005 历史执行证据；默认原始点行为保持。
- 公共入口沿用现有复数 read_om_regions，以一个 method 参数选择；内部计算分层不要求新增用户函数。普通 read_om 仍用于原始网格读取和坐标范围筛选。
- 本期实现显式 points 与 nearest；nearest 的代表位置默认 point_on_surface。区域平均、业务站点意义与代表位置估计分别解释。
- 值列继续使用原名，nearest 保留原始值精度和多变量能力，不另命名成通用 value。

### 默认政策与依赖

- 本次验收声明范围为合成规则球面网格与 ncep_gfs025。其它已登记 domain 不纳入006逐profile验收声明，也不因登记或可读取自动获得已验收状态；运行时仍执行同一通用能力资格检查。
- 代表位置依赖匹配的既有空间能力；允许在依赖版本变化后产生不同合法代表位置，但实际坐标和版本必须可见。同一固定版本不因调度改变。
- max_distance_m 省略无额外阈值，域外默认 NULL，缺测只传播；最大距离可选严格作用于真实地表距离，不使用度作为米。
- 复用 001–005 的值读取、语义轴、网格/布局、区域校验、来源与远程能力。计划阶段冻结最近邻数值核、schema 详情、工作内存预算和运行版本矩阵；不据已实现 reader 推定所有新计算能力已验收。
- `.specify/memory/constitution.md` 仍是未填写模板，其示例不作为已批准原则。当前有效项目契约和本次用户决定为本 spec 依据。

### 明确不在本期

- bilinear/其它插值、面积/覆盖比例权重、区域均值专用聚合、Line、时间/垂直插值、重网格、向量旋转、最近有效值搜索。
- 任意 CRS 识别或自动重投影、极区/接缝复杂多边形范围扩展、投影/Gaussian/曲线网格采样。
- 新点采样函数、单数别名、多对象/跨 chunk 查询、新格式、跨查询缓存、对现有 HTTPFS 或物理 OM reader 职责的替换。

这些未来方向保留在设计提案中，后续按独立可验证的能力分别规格化；不因列入长期设计而扩大 006 完成条件。
