# Scoped N1/N2 refresh provenance

This directory is reserved for the refreshed N1/N2 matrix run on DuckDB v1.5.4, v1.5.5 and v1.5.6. It is separate from earlier packages and retains command identity, source hashes and output hashes.

The evidence status is not predeclared as acceptance: N1 and N2 remain blocked where their finite numeric/profile evidence or residual contract review is incomplete. Historical packages, including `n1-n2-refresh-20261018-scoped`, are not modified.
