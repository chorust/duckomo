# N1 locator foundation checks

**Status: N1 passed for the declared profile scope.** The scope is synthetic regular spherical grids plus NCEP GFS025; other registered domains are excluded from per-profile acceptance. The pure locator, capability validation, spatial-position mapping, and non-spatial cursor have native checks on all three pinned builds. The independent compatibility oracle contains 377 finite capability cases (201 accepted and 176 rejected) plus 12 NCEP GFS025 targets, each exhaustively compared against all 1,038,240 source coordinates. This is the finite acceptance matrix defined by the contract; it does not claim arbitrary binary64 inputs or exhaustive target space. The oracle derivation and reachable rejection-class inventory have been independently reviewed. The ordinary contract-based native fixture lock is defined in `scripts/check-sampling-fixtures.py`.

## Implemented foundation

- `QualifyNearestGrid` validates sphere radius, regular grid kind, in-range monotonic latitude, monotonic finite unwrapped longitude, binary64 coordinate collapse, normalized-meridian uniqueness, wrap limits, and exact `nx * abs(dlon) == 360.0` periodicity.
- `NearestTargetInsideDomain` performs closed raw-latitude coverage and either periodic normalization or a unique unwrapped longitude lift. It does not expand by half a cell.
- `SphereHaversineF64V1` implements explicit exact-coordinate and source-pole branches, binary64 haversine evaluation and distance conversion. `LocateNearestRegularGrid` enumerates all source coordinates with O(1) locator scratch, applies distance then original point index order, and polls cancellation every 256 candidates.
- `SpatialLayout::SourcePosition` reconstructs original file axis positions and logical index from all non-spatial positions plus x/y or flattened point identity, with checked shape and signed-64 arithmetic.
- `NearestAxisCursor` iterates only the non-spatial shape and returns bounded batches; it supports a per-axis selection callback and checked total result upper bound.
