# Feature Specification: 窄范围规则网格 bilinear 区域采样

**Feature Branch**: `main`（仅规格，未切换分支）

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "先处理 005 预算检查与现行接口文档，再收口 003 R21/R22，同时推进 004 当前门禁；之后启动窄范围 bilinear 的方向仍然合理。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在小区域代表位置取得连续标量估计 (Priority: P1)

用户已有区域多边形，希望在与 nearest 相同的面内代表位置取得平滑的连续标量估计，并看清哪些源点参与了计算。

**Why this priority**: 延续小行政区可能不覆盖原始网格点的需求，提供明确的插值方法。

**Independent Test**: 在独立定义的规则网格与矩形区域上，核对代表位置、正权重源索引、权重和可解析参考结果。

**Acceptance Scenarios**:

1. **Given** 合法区域、已验证规则经纬度网格和显式连续标量变量，**When** 选择 bilinear，**Then** 每区域与原始非空间轴组合恰好一行，原变量名的 DOUBLE 值符合独立参考。
2. **Given** 代表位置恰在源点或源边，**When** 执行插值，**Then** 分别仅有一个或两个正权重贡献者，零权重位置不影响值与缺测状态。
3. **Given** 同一输入，**When** 省略 method 或使用现有 points/nearest，**Then** 既有 schema、原值、状态和基数保持各自现行契约。

### User Story 2 - 判断缺测、边界及实际来源 (Priority: P1)

用户需要区分有效估计、源值缺测、空区域与域外，并能检查参与插值的来源。

**Why this priority**: 插值结果需要可解释的支持位置与数值状态。

**Independent Test**: 用正/零权重缺测、周期接缝、非周期端点及正负无穷矩阵核对状态和来源。

**Acceptance Scenarios**:

1. **Given** 任一正权重源值为 NULL，**When** 插值，**Then** 返回 NULL/source_null，保留几何来源；零权重位置的 NULL 不影响结果。
2. **Given** 非周期域的精确端点或端点外侧 nextafter 位置，**When** 插值，**Then** 前者按有效支持点计算，后者按域外策略处理，不外推或夹取。
3. **Given** 经验证的完整周期经度，**When** 目标位于接缝单元，**Then** 正确连接首末列并返回真实索引与权重。
4. **Given** include_source=true，**When** 查询成功，**Then** 可检查每个贡献者的真实原始身份；聚合估计没有伪造的单条 om_source。

### User Story 3 - 保留筛选、来源一致性及有界执行 (Priority: P2)

用户能对同一对象进行本地与远程分析，按非空间轴和最终估计值筛选，并在取消后继续使用连接。

**Why this priority**: 复用现有读取入口与执行保证，支持实际分析流程。

**Independent Test**: 将完整独立计算后筛选的结果与下推查询做双向多重集合比较，核对四来源、线程上限与资源记录。

**Acceptance Scenarios**:

1. **Given** 三个非空间轴及重复坐标标签，**When** 混合筛选与重排列，**Then** 原始轴位置保留，结果与完整计算基准一致。
2. **Given** 仅请求目标坐标或无值依赖计数，**When** 执行，**Then** 值 index/data/decode 均为零；请求值状态或值过滤时读取所需变量。
3. **Given** 本地、HTTP、HTTPS、签名 S3 及 1/2/4 worker 上限，**When** 输入相同，**Then** 完整结果、来源和状态相同；失败/取消后有效查询恢复成功。

### Edge Cases

- EMPTY、空集合、非法/重复 ID、非法 WKB、预算超限及不支持网格在完整输入校验后处理；WHERE/LIMIT 不隐藏绑定错误。
- 升/降序轴、分离/展平布局、周期接缝、精确源点/源边/端点及 nextafter 两侧；拒绝重复坐标、不足两行/两列和未经证明的周期拓扑。
- 正权重 NULL、零权重 NULL、同号无穷及正负无穷混合；分类、角度、向量与单元总量不获得连续标量能力。
- 值过滤不能删除必需贡献点；重复轴标签、重叠区域、提前停止、短读、对象变化和访问失败保留既有语义。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在现有 read_om_regions 中增加显式 method='bilinear'，省略 method 保持 points；points/nearest 的类型、默认值、基数及数值语义不变，不新增公共采样函数。
- **FR-002**: bilinear MUST 要求显式选择一个当前 reader 已支持的数值数组，并明确声明其为适合轴上插值的连续标量。省略变量、自动插值全部数组或声明分类/角度/向量/单元总量均拒绝；不能只凭 FLOAT 存储类型证明连续含义。
- **FR-003**: MUST 复用 006 的 point_on_surface 代表位置及 005 的区域输入约束，每区域 × 原始非空间轴索引组合输出一行。顶层 lat/lon 为目标位置，EMPTY 的目标和值为 NULL。
- **FR-004**: 首版 MUST 仅对已独立验证的完整规则经纬度轴开放，资格与覆盖以 006 规则轴边界为起点，额外要求每空间轴至少两点及四点邻接/权重证据。投影、Gaussian、曲线、不规则及未经证明的 numeric_policy 明确拒绝；可读或可 nearest 不自动赋予 bilinear 能力。
- **FR-005**: MUST 按实际网格坐标轴的分数生成最多四个非负权重，仅保留正权重的不同原始源索引。源点/源边退化由精确坐标关系决定，不能用误差容差把微小正权重归零。权重算法、坐标数值策略和组合顺序有版本身份。
- **FR-006**: MUST 按独立覆盖规则检查目标。合法周期经度允许跨首末列；非周期使用原始轴端点闭域，端点可用已有相邻单元退化计算，不扩大半格、不外推或夹取。域外默认 NULL/outside_domain，可显式选择整个查询失败。
- **FR-007**: 唯一缺测策略 MUST 为 propagate：任一正权重源值 NULL 则该组合为 NULL/source_null；零权重源值不读取、不计贡献且不影响状态。贡献位置与权重不随时间、成员或源值缺测变化，不执行缺测重归一化或最近有效值搜索。
- **FR-008**: MUST 以 DOUBLE 输出原变量名；恰在源点时保留原 FLOAT 转为 DOUBLE 的值，包括符号零。有限输入与独立高精度组合一致。先按 FR-007 处理 NULL；所有正权重源值均非 NULL 时，同号无穷保留其符号，正负无穷混合产生 NULL/numeric_undefined。该规则在计划阶段以版本化数值契约和固定参考冻结。
- **FR-009**: sampling MUST 可解释方法/算法、代表位置策略、网格/布局、原始非空间轴位置、几何状态、变量状态及每个正权重源点的坐标/索引/权重。include_source=true 时再包含既有脱敏对象/版本与真实 logical/parent index；bilinear 的单条 om_source 为 NULL，不伪造原始记录。
- **FR-010**: MUST 保留原始非空间轴与重复标签，不平均、广播、重排或按标签合并。空间权重由绑定几何确定，复用于同区域所有保留轴组合。
- **FR-011**: MUST 在返回前校验整个区域集合、声明与方法相关参数，复用 005 合计 64 MiB 等限制。nearest 专用距离模型/阈值在 bilinear 中显式传入时拒绝；权限、损坏、短读、对象变化与读取失败为查询错误，不降为缺测或域外。
- **FR-012**: MUST 对最终估计值、目标坐标及其完整表达式执行精确 residual；不能通过区域范围或值谓词删掉所需贡献点。非空间轴筛选、投影、COUNT 和值状态依赖保持正确。
- **FR-013**: MUST 在无值依赖的目标坐标、几何来源及计数路径保持值索引/数据/解码为零；请求估计值、缺测状态或值条件时保留依赖。有限贡献点读取复用已有官方 reader/HTTPFS，不扫描全部值寻找邻点。
- **FR-014**: MUST 有界保存位置/权重及执行游标，不物化全域坐标表或全部区域 × 非空间轴结果。计数受检，取消/失败/提前停止有诚实终态、释放自有资源，并可在同连接恢复。
- **FR-015**: MUST 保持四来源与 1/2/4 worker 上限完整结果多重集合、状态、来源和权重一致；沿用官方 HTTPFS 对象稳定性、错误和指标边界，不增加跨查询缓存承诺。
- **FR-016**: 文档与能力声明 MUST 说明连续标量要求、轴上插值、代表位置估计、NULL/无穷、计数、域外及来源；明确其适用范围。交付包含固定参考、实际命令/退出码、产物身份和未参与实现者的独立复现。

### Key Entities

- **连续标量声明**：用户对显式变量的计算含义声明，独立于数组物理类型。
- **代表位置**：由现有区域策略确定的目标位置，与源点及区域统计含义区分。
- **贡献点与权重**：最多四个正权重原始源位置及版本化空间权重，不随轴组合的缺测改变。
- **插值结果**：区域、原始非空间轴组合、DOUBLE 估计值、几何/变量状态及可检查来源。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 冻结解析曲面与独立高精度参考中，源索引及正权重集合 100% 一致；权重绝对误差 ≤1e-14、权重和与 1 的差 ≤8×binary64 epsilon；有限值误差 ≤1e-12×max(1, Σ|参考权重×源值|)。参考不调用生产定位/权重函数。
- **SC-002**: 升降序、两类展平/分离布局、周期接缝、精确节点/边/端点、nextafter、域外、EMPTY、NULL/无穷及不支持能力的固定矩阵，行数、状态、贡献者和拒绝结论 100% 符合契约。
- **SC-003**: 至少一个含三个非空间轴及重复标签的样本，完整独立计算后筛选与优化查询双向多重集合差异为零；既有 points/nearest 回归的 schema、值、来源及状态差异为零。
- **SC-004**: 合成样本与至少一个冻结真实规则网格连续标量样本，四来源及 1/2/4 worker 的完整结果差异为零。真实输入/变量、布局、数值策略、窗口和 SHA256 在验收前冻结，不外推为所有 domain 已验证。
- **SC-005**: 无值依赖用例值 index/data/decode 均为零；固定可跳块局部样本相对同变量全扫的值数据字节与解码块严格减少，HTTP/S3 的独立服务端已发送 body 严格减少。失败和取消不计成功性能样本，不承诺固定收益倍数。
- **SC-006**: 固定区域、线程、非空间轴及块布局，源空间点数扩大至少 10× 时采样工作自有峰值 ≤2×；错误/取消/提前停止后有效查询全部恢复，不完整执行无一报告完整计数。HTTPFS 内部内存与进程 RSS 分开报告。
- **SC-007**: 未参与实现的验证者能仅凭指南复现一次正常插值、一次缺测/域外辨别和一次贡献者核对，保留完整命令、输出、身份及结论；AI 验证明确标识，不冒充人工。

## Assumptions

- 本草案落实 2026-10-21/22 的下一步方向，仅启动规格，不表示 bilinear 当前已可调用。
- 接口沿用 005/006；连续标量声明的具体 SQL 形态、权重公式、组合顺序与 sampling schema 在 plan/contracts 冻结，随后才生成实施任务。不提前建立通用算子 DSL 或新的采样入口。
- 复用现有已冻结 GFS 规则网格输入与独立合成样本，实际真实对象与变量由计划固定；至少覆盖可验证的周期与非周期规则轴。支持等级按验收 profile 隔离。
- 首版不含 projected/Gaussian、renormalize、nearest-valid、Line、面积/单元统计、向量/角度、多变量自动插值、时间/垂直插值或目录拼接。
- 技术依赖为 002 的规则网格/布局、005 的区域输入与预算、006 的代表位置/采样输出及 003 的现行 transport/并行/观测契约。004 完整投影/Gaussian 门禁继续独立推进，阶段编号不构成本草案的全范围依赖。
- 首版实施和验收限定 Linux AArch64、DuckDB v1.5.4/v1.5.5/v1.5.6；每次验收绑定实际源码与产物，不继承其它 spec 的签字。
