# Feature Specification: 多区域 Polygon 读取与等权统计

**Feature Branch**: `main`（本次未创建或切换分支；规格目录独立于分支）

**Created**: 2026-10-11

**Status**: Verified for the declared scope；当前平台、五目标/固定窗口、三版本和独立 AI P7 范围见 [当前验收声明](evidence/current-20261020.md)。

**2026-10-13 验收范围修订**：负责人授权取消全域远程扫描。以下全域比较的原始文字保留为历史；本轮 P5/P6/P7 和 SC-004/FR-020 的现行验收按 [固定局部窗口修订](contracts/bounded-remote-validation-20261013.md)，使用较大窗口普通读取后精确筛面，与同窗口区域入口完整对照；不宣称全域收益或全域吞吐已通过。

**Input**: User description: “空间读取/计算能力：根据 polygon/line 读取 OM、计算均值。优先区域时间序列；Polygon 首版支持多个区域；允许空间功能依赖 DuckDB spatial，普通 read_om 不依赖；先做等权统计，面积加权放后续。”本次只规格化第一项新能力：单对象内的多区域 Polygon 读取与等权统计。跨 chunk 时间序列随后单独规格化，Line 与高级空间计算更晚实施。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 一次读取多个区域中的原始点值 (Priority: P1)

分析者提供一个 OM 对象及一组有稳定区域标识的 Polygon / MultiPolygon，希望得到各区域中的原始网格采样点及值，而不用手写每个区域的经纬度矩形条件。返回的区域归属、采样位置及原有维度可用于后续筛选、分组和核对。

**Why this priority**: 区域选点是统计与区域时间序列的共同基础；只有矩形候选或只有统计结果都不足以检查选中了哪些数据。

**Independent Test**: 将固定对象完整读取并冻结为基准，用独立点面关系参考生成区域—原始记录多重集合；与区域读取结果逐位置、逐值比较，包含重叠区域、洞和 MultiPolygon。

**Acceptance Scenarios**:

1. **Given** 两个带不同区域标识的有效区域和可解释坐标的 OM 对象，**When** 一次读取这组区域，**Then** 每条返回记录带正确区域标识，点坐标、值和其他维度与原始记录一致。
2. **Given** 一个采样点位于两个重叠区域，**When** 读取原始点值，**Then** 该原始记录在两个区域各出现一次；同一区域内不因候选窗口或多部件处理而重复。
3. **Given** 带洞的 Polygon、有效 MultiPolygon，以及恰位于外环或洞边界的点，**When** 进行选点，**Then** 外环内部和所有边界上的点被选中，洞内部的点被排除，不以包围矩形代替精确关系。
4. **Given** 多个原始记录有相同坐标但时间、成员或原始位置不同，**When** 查询区域点值，**Then** 每个原始记录都保留，不按经纬度去重。

---

### User Story 2 - 获得各区域在各时刻的基础统计 (Priority: P1)

分析者对选出的点值计算均值、最小值、最大值、总和与计数，并按区域、有效时间及其他需要的维度分组。原始点值仍可访问，统计不要求使用专用计算语言或固定报告格式。

**Why this priority**: “区域随时间变化的均温”等任务是本阶段直接的用户价值；单对象内已经有时间轴，不必等待跨 chunk 功能。

**Independent Test**: 固定包含多个时刻、成员、缺测和空区域的小样本，以手工可检查的期望值核验各分组结果；再与完整读取后区域筛选的统计对照。

**Acceptance Scenarios**:

1. **Given** 一组区域及对象内已有有效时间坐标，**When** 按区域与时间求均值，**Then** 每组均值等于选中非 NULL 样本的等权平均，并同时可以取得选中记录数与有效值数。
2. **Given** 同一时间有多个 level 或 member，**When** 用户将这些维度加入分组，**Then** 分组相互独立；系统不会提前把这些维度聚合、展开或去重。
3. **Given** 区域 A 没有选中点、区域 B 选中了点但该时刻值均缺测，**When** 按文档查询统计与计数，**Then** A 的样本数为零，B 的样本数大于零而有效值数为零，二者均不得解释为数值零。
4. **Given** 区域无点或某组全部值为 NULL，**When** 查询原始点值或基础聚合，**Then** 原始入口不制造占位样本；空分组可由用户提供的区域/时间集合补齐，缺测组均值、最小值、最大值及总和为 NULL、有效值数为零。

---

### User Story 3 - 查询局部区域而不必读取全部值 (Priority: P1)

分析者从本地或远程大对象读取小区域，希望保留精确结果，同时在具备可跳过数据块的布局中减少读取与解码成本。仅查询区域归属、位置或无值条件的计数时，不应读取值数据。

**Why this priority**: 全量下载后过滤虽可演示空间关系，却不能作为本功能完整交付；按需读取是已有产品能力在区域查询上的延续。

**Independent Test**: 在测量前冻结各目标网格的真实样本、较大局部基准窗口、区域和输出列；完整消费窗口普通读取后精确筛面与区域入口的结果，逐源位置精确比较，并核对读取/解码和服务端发送量。

**Acceptance Scenarios**:

1. **Given** 已冻结的可跳块样本和局部区域，**When** 完整执行相同值列的较大局部窗口基准与区域读取，**Then** 区域结果与基准精确一致，值数据读取量和解码块数均严格减少。
2. **Given** 同内容的本地、HTTP(S) 和签名 S3 对象，**When** 使用相同区域和维度条件读取，**Then** 区域、原始位置、坐标、值及缺测一致；不同 URI 的对象身份不要求相同。
3. **Given** 仅位置/区域归属/无值条件计数或可证明为空的选择，**When** 完整执行查询，**Then** 值索引、值数据读取及值块解码均为零；必要元数据和坐标准备成本单独记录。
4. **Given** 查询含值过滤条件，**When** 值列没有投影到结果中，**Then** 仍保留该过滤依赖，不能错误使用零值读取路径。
5. **Given** 区域数量多、几何复杂或候选表达过大，**When** 无法维持精细候选选择，**Then** 可以退回较宽候选但不能漏点，且仍须执行精确区域关系并保持有界工作内存。

---

### User Story 4 - 理解输入错误和执行边界 (Priority: P2)

分析者能判断几何输入是否适用、空结果意味着什么，以及取消或失败后如何重新查询。使用普通 OM 读取的用户不应被迫安装或加载空间功能依赖。

**Why this priority**: 防止坐标系误用和静默修复产生看似合理的错误统计，并保证新功能不破坏既有读取。

**Independent Test**: 提交无效标识、无效几何、不支持的坐标范围与缺失依赖，再执行取消、读取失败和恢复测试；确认普通读取行为保持不变。

**Acceptance Scenarios**:

1. **Given** 任一区域标识为 NULL 或重复，或输入为无效/非面几何，**When** 发起区域读取，**Then** 整个请求明确失败，不静默跳过、合并或修复该区域。
2. **Given** 未具备空间功能依赖，**When** 使用区域读取，**Then** 给出可操作的依赖诊断；普通读取仍可执行且 schema 不变。
3. **Given** 查询正在进行坐标准备、区域判断或值读取，**When** 用户取消，**Then** 查询终止并释放本次资源，随后有效查询可以成功；失败/取消记录不能标为完整成功收益。
4. **Given** 输入区域涉及未经支持的跨接缝或极区解释，**When** 请求读取，**Then** 明确拒绝并说明首版范围，不能悄悄按另一种几何解释返回结果。

### Edge Cases

- 输入区域集合为空：返回零条原始记录，不读取值；仍检查请求参数的合法性。
- 有效的 EMPTY Polygon / MultiPolygon：保留其区域身份供用户结果补齐，但没有样本；NULL 几何是错误而非空区域。
- 两个不同区域 ID 对应相同几何：各自产生完整区域结果，不跨区域去重。
- MultiPolygon 必须整体有效；自交、非法洞、重叠造成无效的部件不能通过自动修复掩盖。
- 外环和洞边界都包含；边界判断不能借坐标参考容差擅自扩大区域。
- 经度接缝附近的输入、极区包围、非有限坐标、混合或未知坐标系按 FR-003/004 处理。
- 全部值缺测、NaN、正负无穷沿用既有读取和宿主聚合语义；不得把无穷静默改为 NULL，也不承诺此类组得到有限均值。
- 同一地理位置上的不同时间/member/level 和原始位置保持独立记录。
- 区域选择与时间条件、值条件、投影、排序、聚合组合时，不漏掉过滤列或原有完整条件。
- 提前停止、LIMIT、失败或取消不得用于证明完整计数和收益；查询恢复不能复用失效的本次状态。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 对单个受支持 OM 对象接受一组带唯一、非 NULL 区域标识的 Polygon / MultiPolygon，并让用户一次获得多个区域的结果；本期不要求逐区域手写独立读取。
- **FR-002**: 系统 MUST 验证完整区域集合，拒绝重复/NULL 标识、NULL 几何、非面类型、非法拓扑和非有限坐标；允许空集合和有效空面，不静默修复或跳过非法项。
- **FR-003**: 首版 MUST 要求输入区域显式采用与所选网格输出一致的经纬度坐标参考和经度在前、纬度在后的顺序；经度限于 [-180,180]、纬度限于 [-90,90]。不根据数值猜测坐标系，不执行隐式投影或 datum 转换，不将 producer 坐标一致性宣称为原生 GRIB 或任意 CRS 等价。
- **FR-004**: 首版 MUST 使用同一经纬度平面内的直线边和点面覆盖关系；拒绝经度包围跨度达到或超过 180°、任一边跨越经度接缝、接触纬度 ±90° 或需要极区包围解释的区域。用户可先拆成多个局部合法区域并明确各自 ID；首版不自动拼接这些区域或进行球面解释。
- **FR-005**: 系统 MUST 选择区域内部及所有边界上的原始网格采样点，排除洞内部；不把点样本解释为有面积的单元，不用矩形包围范围替代最终精确关系。
- **FR-006**: 对每个“区域标识、原始记录位置”组合 MUST 最多输出一次。不同区域分别保留匹配记录；不同原始位置即使经纬度相同也不得去重。原始记录位置可供用户追溯核对。
- **FR-007**: 输出 MUST 保留区域标识、选中值和可供查询的坐标及既有语义维度；与输入列名冲突时须明确诊断而非覆盖。未选网格或无法证明空间位置时不能进行地理区域读取。
- **FR-008**: 区域读取 MUST 能与既有列选择、时间/其他维度筛选及值条件组合；完整用户条件始终有效，不隐式转置、广播、推导时间或合并非空间维度。
- **FR-009**: 系统 MUST 让返回值可按区域和时间等维度进行等权点样本聚合；无须专用统计引擎即可得到非 NULL 值的均值、最小值、最大值、总和，以及对应样本总数和有效值数。系统不将点均值标为面积平均，也不能把宿主聚合的 NULL/非有限值语义改成静默默认。
- **FR-010**: 原始入口 MUST 不伪造空区域或空时段记录。文档 MUST 提供使用显式区域/时间集合补齐空结果的流程，以及区分“零样本”和“有样本但全 NULL”的计数方法。无值组的数值统计不得默认填零。
- **FR-011**: 无已识别或显式声明时间轴的对象 MUST 仍可进行纯空间读取，但不得从文件路径推断有效时间；本期时间分组只使用既有单对象维度证据。
- **FR-012**: 区域选择 MUST 在可跳块布局上减少不必要的值读取和解码；无法安全缩小候选时允许扩大或回退，但精确区域关系及其他条件不得丢失。不承诺任意区域、布局或区域数都有收益。
- **FR-013**: 仅位置、区域归属、无值条件计数和可证空选择 MUST 保持值索引/值数据/值解码零成本；输出或过滤需要的值依赖 MUST 保留。
- **FR-014**: 同内容本地、HTTP(S)、S3 的结果 MUST 一致，并沿用当前授权和可观察对象变化诊断；扫描期间对象稳定的既有前提不变。不新增凭据管理、跨对象快照或热缓存收益承诺。
- **FR-015**: 候选、任务及输出工作内存 MUST 有明确上界，不随对象总点数或历史请求数无界累积。区域输入本身的存储与扫描工作内存分列；不允许为优化预先物化所有“区域×网格点”匹配关系。具体容量预算在设计阶段冻结。
- **FR-016**: 并行、跨批次、取消、失败、LIMIT 和恢复 MUST 保持区域—原始记录语义，无遗漏或额外重复；必须区分完整成功、提前停止、取消和失败。
- **FR-017**: Polygon 功能 MAY 要求 DuckDB spatial；普通 `read_om` MUST 继续不依赖该扩展且不改变默认输出。既有单对象入口不得因本功能隐式接受多文件或强制产生区域列。
- **FR-018**: 验证 MUST 使用预先冻结的对象、区域、参考、查询、输出依赖及构建条件，区分结果正确性与读取收益；独立几何基准不得调用待测区域选择逻辑，官方值参考和 producer 坐标来源保持可追溯。
- **FR-019**: 收益记录 MUST 完整消费结果，分别报告应用读取、解码和远端服务发送量；不能将服务端发送量冒充客户端接收量，也不能将未知计量补零。未执行或失败的场景不得登记为通过。
- **FR-020**: 交付文档 MUST 明确逐网格/对象/来源验证范围、几何与均值语义、依赖及不支持项，并支持未参与实现的验证者复现多区域读取、时间统计和一次固定较大窗口/区域的远程比较。

### Key Entities

- **区域集合**：一次请求中的区域 ID 与有效面几何集合；标识在集合内唯一，几何可重叠。
- **区域几何**：与网格输出参考一致的 Polygon / MultiPolygon，含外环、洞及明确边界规则；不是网格单元覆盖率。
- **原始采样记录**：一个 OM 对象中的原始位置、网格采样点、值及全部非空间维度；经纬度相同不等于记录相同。
- **区域样本**：一个区域与一个匹配原始记录的关系，是普通分组聚合的输入。
- **区域时间统计**：按用户选择的区域、时间及其他维度形成的等权统计、总样本数和有效值数；不自动补齐不存在的时刻。
- **验证记录**：固定样本、区域和参考对应的完整结果、成本、终态及支持范围，用于区分功能实现和已验证能力。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 所有冻结的点面验收样本中，区域—原始记录集合与独立全量基准的双向差异为零，坐标、原始值及 NULL 一致；覆盖洞、边界、MultiPolygon、重叠和空区域。（FR-001–008）
- **SC-002**: 一个固定样本至少包含 10 个区域、3 个时刻和 2 个成员；各组总样本数/有效值数与参考精确一致，有限值的均值和总和相对误差不超过 1e-6、接近零时绝对误差不超过 1e-6（值单位），最小值/最大值精确一致。参考在测试前冻结并包含可手工核验的小例子。（FR-009–011）
- **SC-003**: 零样本与全 NULL 两类固定场景均能通过文档流程正确识别；原始结果不增加占位行，全部非法输入用例给出明确拒绝，不静默生成统计。（FR-002–004/010）
- **SC-004**: 在规则、rotated、Lambert、stereographic 和 O1280 各一个事前固定的真实对象上，按 [2026-10-20 成本修订](contracts/non-increasing-cost-20261020.md)，每个 HTTP/签名 S3 对照的值读取字节、解码块数及服务端发送量相对冻结较大局部窗口均不得增加，且至少一项严格下降；所有完整结果与本地参考一致。只声明固定窗口范围，不外推全域或同类其他网格。（FR-012/014/018/019）
- **SC-005**: 所有仅位置/归属/无值计数/可证空验收用例的值索引读取、值数据读取和解码为零；含值过滤的对照结果与全量参考一致。（FR-013）
- **SC-006**: 1/2/4 个工作线程的完整结果多重集合相同；固定区域集合、相同数据块布局和相近窄结果下，对象空间点数扩大至少 10 倍，扫描工作内存峰值不超过原来的 2 倍。所有取消/失败场景之后的有效查询均成功且状态无串扰。（FR-015/016）
- **SC-007**: 未参与实现的验证者仅凭交付指南和冻结输入，可以完成多区域原始点值查询、分时统计、空/缺测辨别及一次远程收益对比，记录命令、结果和结论；普通读取回归无需空间依赖即可通过。（FR-017/020）

## Assumptions

### Confirmed scope and sequencing

- 用户已确认：多区域首版支持；优先区域时间序列；空间功能可以依赖 DuckDB spatial、普通读取不依赖；首版等权统计，面积加权后续做。
- 本 spec 只涉及一个稳定 OM 对象中的区域读取及其已有时间轴。完成后优先单独设计跨 chunk 时间序列，再根据场景设计 Line；面积加权、插值、重网格不是本次默认交付。
- 先核验所依赖的坐标、源位置和选择基线，再实现区域关系、原始点值、分组统计及局部收益。复杂空间索引、跨区域共享读取和缓存优化不是首版要求；不允许以此推迟基本局部读取验收。

### Explicit defaults

- 首版使用点样本覆盖而非单元相交；外环及洞边界包含。输入面必须有效，禁止隐式修复。
- 首版采用局部经纬度平面语义，不承诺地球曲面距离/面积或全球包围几何。FR-004 的限制是保守的首版产品范围，避免日期变更线/极区被误解；扩大该范围需单独修改规格与参考用例。
- 区域 ID 的具体类型、几何输入载体、公开调用形式、输出冲突策略和容量预算由后续设计确定；本规格固定用户可观察行为，不预先命名新函数或选择执行算法。
- 默认只返回实际匹配记录，不自动生成区域×时间笛卡尔积；完整报表由显式区域/时间集合组合得到。点值统计遵循既有 NULL 和非有限值语义，不隐式跨 level/member 等维度聚合。

### Dependencies and verification boundaries

- 复用 001–004 的单对象读取、网格坐标/布局、维度和过滤能力；需要可信的依赖范围测试，不要求所有历史验收先标 verified 才能开始设计。坐标错误或候选漏点属于必须先修复的阻塞。
- 当前基线为 Linux AArch64、DuckDB v1.5.4/v1.5.5/v1.5.6 和官方 HTTPFS；不同版本使用匹配产物和实际兼容的空间依赖。版本与具体输入在后续设计中冻结，不据既有发布矩阵扩大本期深度验证平台。
